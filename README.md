## Troubleshooting Common Issues

Install issues? Install with administrative rights and confirm all required toolsets were selected.  
Performance problems? Unload unused links, limit open views, and keep central models on a fast local network.  
License/activation? Assign the subscription seat to the correct Autodesk account before first launch.  
Compatibility? Upgrade all linked models together when the project moves to a newer release.  
Update failures? Use the Autodesk desktop app for updates so toolsets stay in sync.
